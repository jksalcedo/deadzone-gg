# Deadzone

A fast-paced LAN multiplayer shooter built with Godot 4, playable in third-person (TPS) or first-person (FPS). Host or join sessions over a direct IP connection with no relay servers required. Features a weapon system, health & respawn mechanics, and a minimal monochrome HUD.

## Features

- [x] Player movement with head bobbing and landing recovery
- [x] Third-person camera / TPS (default) with first-person / FPS toggle
- [x] Weapon system with raycast shooting, recoil, and reload
- [x] HUD — health bar, ammo counter, damage vignette, hitmarker
- [x] LAN multiplayer via ENet (host / join by direct IP)
- [x] Server-authoritative health and damage sync
- [x] Player respawn with full health reset
- [x] Main menu with host / join / singleplayer practice modes
- [ ] Kill feed / scoreboard
- [ ] Sound effects and music
- [ ] Multiple maps
- [ ] Lobby system
